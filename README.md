Elevate Labs Task 4 - Dashboard Design
Objective
Design an interactive sales dashboard for business stakeholders.
Dataset
Sales dataset containing 1,200 records and 9 columns: Order_ID, Date, Region, State, Category, Product, Quantity, Sales, Profit.

Total Profit
Total Quantity
Sales Growth %

Interactive Filters / Slicers
Date
Region

Product
Key Insights
Technology is the strongest sales category.
North America has the highest regional sales.
Europe is the second-highest regional contributor.
Monthly sales fluctuate over time.
Technology has the strongest profit contribution.
Tools
Power BI, CSV/Excel, GitHub
Deliverables
Interactive dashboard, PPT summary, dataset, README.
Note
The PPT summary and dashboard design use the sales dataset previously analyzed in Task 2. The final interactive Power BI dashboard should be recreated in Power BI Desktop or Power BI Service.
